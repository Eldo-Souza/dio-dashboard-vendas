# Dashboard de Vendas — Xbox Game Pass

Projeto desenvolvido em Excel como parte de um desafio da DIO, com o objetivo de transformar dados brutos em informações visuais para apoiar a análise de vendas e a tomada de decisões.

## 📌 Sobre o projeto

O projeto apresenta um dashboard de assinaturas relacionadas ao Xbox, com análises sobre planos, renovação automática e adesão a serviços adicionais. A solução reúne uma base de dados, cálculos auxiliares e um painel visual em um único arquivo Excel.

## 🎯 Objetivo do desafio

- Criar um dashboard no Excel para organizar e visualizar dados.
- Transformar os dados em informações úteis para análise do desempenho.
- Praticar a organização de dados e a construção de visualizações para apoiar decisões.

## 📊 Estrutura do arquivo

O arquivo `DASHBOARD-VENDAS.xlsx` contém quatro abas:

- **Dashboard:** painel visual com o título _Xbox Game Subscriptions Sales_.
- **Bases:** dados de assinaturas, incluindo identificador e nome do assinante, plano, data de início, renovação automática, preço e informações sobre serviços adicionais.
- **Cálculos:** área de apoio com cálculos e análises para responder a perguntas de negócio, incluindo faturamento de planos anuais e comparação por renovação automática.
- **Assets:** elementos de apoio visual, como paleta de cores, logos e ícones.

As abas **Bases**, **Cálculos** e **Assets** estão ocultas no arquivo; a aba **Dashboard** é a área principal de visualização.

## 🔎 Dados e análises

A base utilizada contém informações de assinaturas, como:

- Plano contratado e tipo de assinatura;
- Data de início;
- Indicação de renovação automática;
- Preço da assinatura;
- Adesão e preços de serviços adicionais, como EA Play e Minecraft;
- Valores de cupons.

A área de cálculos inclui análises de faturamento de planos anuais, inclusive uma separação entre assinaturas com e sem renovação automática.

## 🛠️ Tecnologia utilizada

- Microsoft Excel

## ▶️ Como utilizar

1. Baixe ou clone este repositório.
2. Abra `DASHBOARD-VENDAS.xlsx` no Microsoft Excel.
3. Acesse a aba **Dashboard** para visualizar o painel.

As abas auxiliares estão ocultas para manter o foco no dashboard. Caso seja necessário examinar os dados ou cálculos, elas podem ser reexibidas no Excel.
